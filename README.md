# hidden-word

Application 100% front-end autour du mot caché. Concept à définir.

React 19 + TypeScript, Vite, Tailwind CSS v4, Vitest.

## Démarrer

```bash
make install
make start
```

Le serveur de dev tourne sur http://localhost:1515.

## Commandes

| Commande | Effet |
|---|---|
| `make install` | Installe les dépendances |
| `make start` | Serveur de dev |
| `make build` | Build de production |
| `make test` | Tests |
| `make check` | build + lint + typecheck + knip + tests |

Voir [AGENTS.md](AGENTS.md) pour la stack, l'arborescence et les conventions.
